# Candidate pipeline — the two core verticals

The scope decision (`docs/DIRECTION.md` → Directory scope) is to grow **AI &
developer tools** and **privacy & security** to 15–20 verified records each. The
shipped `editorial_seed.json` has ~6 in each. This file is a research starting
point for the rest — **candidates, not verified records.**

## How to use it

1. Open the Research Lab (Profile → Developer → Research Lab).
2. For each candidate below: search for their **author page** on the outlet's
   site (linked or described), confirm the byline is current and the beat
   matches, pull **2–4 recent dated articles** with real URLs.
3. Enter them as a new candidate, attach the articles, set your initials, and
   **Verify** — or **Reject** if they've moved on / the beat doesn't hold up.
4. Export and commit the updated `editorial_seed.json`.

**Rules (unchanged):** public editorial signal only — outlet, beat, dated
bylines, public bio. No email, phone, socials, or "how to pitch me" notes.
Never mark verified without opening the source yourself. AI discovered these;
you verify them.
